## 📌 Project Overview

This project focuses on analyzing the usage of Artificial Intelligence (AI) tools among Indian college students.

The project explores students' AI tool preferences, daily usage patterns, trust levels, academic impact, awareness, and willingness to pay.

The complete project is organized into four parts, covering data preprocessing, exploratory data analysis, feature engineering, machine learning, and model evaluation.

## 🎯 Project Objectives

- Analyze AI tool usage among Indian college students.
- Understand students' preferences and usage patterns.
- Explore the relationship between AI usage and academic performance.
- Identify important factors influencing AI tool adoption.
- Apply machine learning techniques to the collected dataset.
- Evaluate model performance and derive meaningful insights.

## 📊 Dataset Information

The dataset contains information about Indian college students.

**Dataset Size:**
- Rows: 3,614
- Columns: 16

**Features:**
1. Student Name
2. College Name
3. Stream
4. Year of Study
5. AI Tools Used
6. Daily Usage Hours
7. Use Cases
8. Trust in AI Tools
9. Impact on Grades
10. Professors' Permission
11. Preferred AI Tool
12. Awareness Level
13. Willingness to Pay
14. State
15. Device Used
16. Internet Access

# 📁 Project Modules

## Part 1: Data Preprocessing and Exploratory Data Analysis (EDA)

**Objective:** Clean, analyze, visualize, and prepare the dataset for machine learning.

### Data Preprocessing
- Missing value analysis.
- Median-based missing value imputation.
- Duplicate record identification and removal.
- Data type conversion.
- Descriptive statistical analysis.
- Skewness analysis.
- Outlier detection using the IQR method.

### Exploratory Data Analysis

The following visualizations were created:

- Line Plot
- Bar Chart
- Histogram
- Scatter Plot
- Box Plot
- Correlation Heatmap

### Statistical Analysis
- Pearson Correlation
- Spearman Correlation
- Grouped Aggregation

### Key Findings

- Highest mean daily usage: Pharmacy (2.744 hours).
- Highest standard deviation: Management (1.328).
- Highest absolute skewness: Awareness_Level (-0.15283).
- Highest mean / lowest mean ratio: 1.22.

### Output

The cleaned dataset was saved as:

`cleaned_data.csv`
